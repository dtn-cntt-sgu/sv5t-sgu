# Lora webfonts

Unmodified static WOFF2 fonts from the author's **v3.021** release:
https://github.com/cyrealtype/Lora-Cyrillic/tree/v3.021/fonts/webfonts

Distributed under the SIL Open Font License 1.1; see `OFL.txt` and
`FONTLOG.txt` for the license, credits, and font information.

These full fonts contain Latin letters, Vietnamese precomposed characters,
and combining accents together. `app/layout.tsx` loads them with
`next/font/local`, so auth headings do not depend on installed fonts or
separate Google Fonts Unicode subsets. Regular, Medium, and Italic cover
the weights and styles used by the login and registration pages.
